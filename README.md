# Домашки курса «Микросервисы на Go 3.0»

Здесь ты восемь недель строишь свой проект: сервисы заказов, склада и оплаты, которые к концу курса становятся системой с Kafka, Redis, авторизацией и наблюдаемостью.

Условия домашек и правила сдачи лежат на платформе курса: https://platform.olezhek28.courses

## Как начать

1. Получи доступ к репозиторию с примерами из курса [olezhek28-paid-courses/microservices-3-0](https://github.com/olezhek28-paid-courses/microservices-3-0): там же лежат заготовки домашек. Платформа выдаёт доступ, когда ты подключаешь GitHub. Если доступа нет, на платформе будет кнопка «Получить доступ».
2. Склонируй репозиторий с примерами себе на компьютер, в соседнюю папку с этим репозиторием:

   ```bash
   git clone https://github.com/olezhek28-paid-courses/microservices-3-0.git
   ```

3. Возьми заготовку первой недели по шагу 0 из текста домашки 1. Дальше каждая неделя говорит, что добавить из своей заготовки.

## Как сдавать

Через пул-реквесты в этом репозитории. Сколько их и что в каждом, написано в тексте домашки недели.

## Права

Репозиторий приватный, держи его таким. Код заготовок и примеров курса платный, не выкладывай его в открытый доступ.
